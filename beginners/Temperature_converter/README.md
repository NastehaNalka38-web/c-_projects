### Temperature Converter App

![temperature](/beginners/Temperature_converter/Screenshoots/tempConvertApp.png)

The Temperature Converter is an app that converts temperature values between Celsius (°C) and Fahrenheit (°F).

### Convert Button
Convert button: Converts Celsius to Fahrenheit or Fahrenheit to Celsius.


### Reset Button
Reset button: Clears the input and result, and restores the default selections.

### Exit Button
Exit button: Closes the application.


### Invalid input
