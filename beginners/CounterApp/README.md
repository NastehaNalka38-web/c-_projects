### Increase Button
![increase](/beginners/CounterApp/Screenshoots/IncreaseImg.png)

the Increase button (+) adds 1 to the current counter value every time the user clicks it.

### Decrease Buttom
![Decrease](/beginners/CounterApp/Screenshoots/DecreaseImg.png)

the Decrease button (−) subtracts 1 from the current counter value every time the user clicks it.

### Reset Button
![Reset](/beginners/CounterApp/Screenshoots/ResetImg.png)

the Reset button returns the counter value to 0 whenever the user clicks it.
